# Changelog

## 1.1.0 — Final release

- Added rated and private multiplayer chess.
- Added six clock formats and six practice bot levels.
- Added same-settings bot rematches.
- Added server-authoritative chess, clocks, ratings, results, and reconnect handling.
- Added 30-second reconnect grace and second-disconnect forfeits.
- Added draw offers, resignation, chat, spectating, PGN, FEN, match history, and Stockfish review.
- Added email verification, Google sign-in, Argon2, sessions, account controls, rate limits, Helmet, CSP, and SQL/input protections.
- Added profiles, leaderboards, friends, DMs, notifications, blocking, reporting, presence, and moderation.
- Added seven board themes, responsive layout, SVG pieces, result animations, victory GIF, and completed leaderboard GIF section.
